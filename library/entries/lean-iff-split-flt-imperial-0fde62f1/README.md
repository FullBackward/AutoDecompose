## Intent

The main result "`ρ` is irreducible iff it is absolutely irreducible" is
split into its two directions, each closed by one named lemma: the hard
direction base-changes irreducibility to the algebraic closure, the easy
direction descends it. The glue is a nine-line `constructor` proof that
instantiates both lemmas at `AlgebraicClosure k`.

```lean
theorem isIrreducible_iff_isAbsolutelyIrreducible_slop
    [FiniteDimensional k V]
    {g : G} (hg : finrank k (Module.End.eigenspace (ρ g) 1) = 1) :
    ρ.IsIrreducible ↔ IsAbsolutelyIrreducible ρ := by
  unfold IsAbsolutelyIrreducible
  constructor
  · -- hard direction: irreducible ⇒ irreducible after base change to `k̄`
    intro hirr
    exact isIrreducible_baseChange_of_finrank_eigenspace_eq_one ρ
      (AlgebraicClosure k) hirr hg
  · -- easy direction: irreducibility descends along `k → k̄`
    intro habs
    exact isIrreducible_of_baseChange ρ (AlgebraicClosure k) habs
```

```lean
theorem isIrreducible_baseChange_of_finrank_eigenspace_eq_one
    [FiniteDimensional k V]
    (l : Type*) [Field l] [Algebra k l]
    (hirr : ρ.IsIrreducible)
    {g : G} (hg : finrank k (Module.End.eigenspace (ρ g) 1) = 1) :
    (baseChange l ρ).IsIrreducible := by
  -- Lemma 1.4 : every `G`-equivariant endomorphism of `V` is a scalar.
  have hEnd : ∀ T : Module.End k V, (∀ h : G, Commute (ρ h) T) →
      ∃ μ : k, T = μ • (1 : Module.End k V) :=
    fun T hT => exists_smul_eq_of_commute ρ hirr hg T hT
  -- Lemma 1.5 : the `k`-algebra generated by `ρ(G)` is all of `End_k V`.
  have hA : adjoinRange ρ = ⊤ := adjoinRange_eq_top ρ hirr hEnd
  -- Lemma 1.6 : this stays true after base change to `l`.
  have hAbc : adjoinRange (baseChange l ρ) = ⊤ := adjoinRange_baseChange_eq_top ρ l hA
  -- `l ⊗[k] V` is nontrivial : a nonzero `v ∈ V` gives a nonzero `1 ⊗ v`.
  have : Nontrivial V := ((isIrreducible_iff_forall ρ).mp hirr).1
  obtain ⟨v, hv0⟩ := exists_ne (0 : V)
  obtain ⟨φ, hφ⟩ := Module.Projective.exists_dual_eq_one k hv0
  have hne : (1 : l) ⊗ₜ[k] v ≠ 0 := by
    intro hzero
    have hcontra := congrArg
      (fun t => (TensorProduct.rid k l).toLinearMap (LinearMap.lTensor l φ t)) hzero
    simp only [LinearMap.lTensor_tmul, LinearEquiv.coe_coe, TensorProduct.rid_tmul, hφ,
      one_smul, map_zero] at hcontra
    exact one_ne_zero hcontra
  have : Nontrivial (l ⊗[k] V) := nontrivial_of_ne _ _ hne
  -- Step (iv) : fullness of the algebra forces irreducibility.
  exact isIrreducible_of_adjoinRange_eq_top (baseChange l ρ) hAbc
```

```lean
lemma isIrreducible_of_baseChange (l : Type*) [Field l] [Algebra k l]
    (h : (baseChange l ρ).IsIrreducible) :
    ρ.IsIrreducible := by
  obtain ⟨hntl, hsubl⟩ := (isIrreducible_iff_forall (baseChange l ρ)).mp h
  refine (isIrreducible_iff_forall ρ).mpr ⟨?_, ?_⟩
  · -- `Nontrivial V` : otherwise `l ⊗[k] V` would be trivial, contradicting `hntl`.
    by_contra hV
    rw [not_nontrivial_iff_subsingleton] at hV
    have : Subsingleton V := hV
    have : Subsingleton (l ⊗[k] V) := by
      refine ⟨fun a b => ?_⟩
      have hz : ∀ x : l ⊗[k] V, x = 0 := fun x => by
        induction x using TensorProduct.inductionOn with
        | tmul a v => rw [Subsingleton.elim v (0 : V), TensorProduct.tmul_zero]
        | add a b ha hb => rw [ha, hb, add_zero]
      rw [hz a, hz b]
    exact not_nontrivial_iff_subsingleton.mpr inferInstance hntl
  · -- Any invariant `W` gives an invariant `l ⊗[k] W`, which is `⊥`/`⊤` by `hsubl`; descend.
    intro W hW
    have hinv : ∀ g : G, ∀ x ∈ W.baseChange l, (baseChange l ρ) g x ∈ W.baseChange l := by
      intro g x hx
      change LinearMap.baseChange l (ρ g) x ∈ W.baseChange l
      rw [Submodule.baseChange_eq_span] at hx
      induction hx using Submodule.span_induction with
      | mem y hy =>
        obtain ⟨w, hw, rfl⟩ := hy
        simp only [TensorProduct.mk_apply, LinearMap.baseChange_tmul]
        exact Submodule.tmul_mem_baseChange_of_mem 1 (hW g w hw)
      | zero => rw [map_zero]; exact Submodule.zero_mem _
      | add a b _ _ ha hb => rw [map_add]; exact Submodule.add_mem _ ha hb
      | smul c a _ ha => rw [map_smul]; exact Submodule.smul_mem _ c ha
    rcases hsubl (W.baseChange l) hinv with hb | ht
    · exact Or.inl <| Submodule.baseChange_injective (A := l)
        (hb.trans (Submodule.baseChange_bot (R := k) (M := V) (A := l)).symm)
    · exact Or.inr <| Submodule.baseChange_injective (A := l)
        (ht.trans (Submodule.baseChange_top (R := k) (M := V) (A := l)).symm)
```

```lean
/-- A representation is absolutely irreducible if it remains irreducible after
base change to an algebraic closure of `k`. -/
def IsAbsolutelyIrreducible (ρ : Representation k G V) : Prop :=
  (baseChange (AlgebraicClosure k) ρ).IsIrreducible
```

```lean
/-- Base change of a representation along a field extension `l/k`:
`G` acts on `l ⊗[k] V` by `1 ⊗ ρ(g)`. -/
noncomputable def baseChange (l : Type*) [Field l] [Algebra k l]
    (ρ : Representation k G V) : Representation l G (l ⊗[k] V) where
  toFun g := (ρ g).baseChange l
  map_one' := by
    change (ρ 1).baseChange l = 1
    have h1 : ρ 1 = LinearMap.id := by rw [map_one]; rfl
    rw [h1, LinearMap.baseChange_id]
    rfl
  map_mul' := fun g h => by
    change (ρ (g * h)).baseChange l = (ρ g).baseChange l * (ρ h).baseChange l
    have h1 : ρ (g * h) = (ρ g).comp (ρ h) := by rw [map_mul]; rfl
    rw [h1, LinearMap.baseChange_comp]
    rfl
```

```lean
lemma isIrreducible_iff_forall :
    ρ.IsIrreducible ↔
      Nontrivial V ∧
        ∀ W : Submodule k V, (∀ g : G, ∀ v ∈ W, ρ g v ∈ W) → W = ⊥ ∨ W = ⊤ := by
  constructor
  · intro hirr
    have := hirr
    refine ⟨?_, ?_⟩
    · -- `V` is nontrivial because `⊥ ≠ ⊤` in the (simple) lattice of subrepresentations.
      exact (Submodule.nontrivial_iff k).mp
        (nontrivial_of_ne (⊥ : Submodule k V) ⊤
          (fun e => IsSimpleOrder.bot_ne_top (α := Subrepresentation ρ)
            (Subrepresentation.toSubmodule_injective
              (show (⊥ : Subrepresentation ρ).toSubmodule = (⊤ : Subrepresentation ρ).toSubmodule
                from e))))
    · -- An invariant subspace `W` is a subrepresentation, hence `⊥` or `⊤`.
      intro W hW
      rcases eq_bot_or_eq_top (⟨W, fun g v hv => hW g v hv⟩ : Subrepresentation ρ) with hb | ht
      · exact Or.inl (congrArg Subrepresentation.toSubmodule hb)
      · exact Or.inr (congrArg Subrepresentation.toSubmodule ht)
  · rintro ⟨hnt, hforall⟩
    have : Nontrivial V := hnt
    have : Nontrivial (Submodule k V) := (Submodule.nontrivial_iff k).mpr hnt
    refine
      { toNontrivial := ⟨⊥, ⊤, ?_⟩
        eq_bot_or_eq_top := ?_ }
    · -- `⊥ ≠ ⊤` as subrepresentations, since the underlying submodules differ.
      exact fun e => bot_ne_top (α := Submodule k V) (congrArg Subrepresentation.toSubmodule e)
    · -- Every subrepresentation `s` has invariant underlying submodule, so it is `⊥` or `⊤`.
      intro s
      rcases hforall s.toSubmodule (fun g v hv => s.apply_mem_toSubmodule g hv) with hb | ht
      · exact Or.inl (Subrepresentation.toSubmodule_injective hb)
      · exact Or.inr (Subrepresentation.toSubmodule_injective ht)
```

The parent splits the biconditional with `constructor` (the iff-split), which
creates exactly two goals; each is closed by instantiating one named lemma at
`AlgebraicClosure k`:

- the **hard** direction `ρ.IsIrreducible ⇒ IsAbsolutelyIrreducible ρ` is
  `isIrreducible_baseChange_of_finrank_eigenspace_eq_one` (lines 447-474),
  stated over an arbitrary extension `l/k` and specialised here to
  `AlgebraicClosure k`;
- the **easy** direction `IsAbsolutelyIrreducible ρ ⇒ ρ.IsIrreducible` is
  `isIrreducible_of_baseChange` (lines 405-440), which descends irreducibility
  from the base change.

Why each leaf is a good leaf:

- `isIrreducible_of_baseChange` is a self-contained descent whose proof closes
  on its own: it unpacks both sides with `isIrreducible_iff_forall` and shows
  every invariant subspace of `V` descends from the base-changed one via
  `Submodule.baseChange_injective`.
- `isIrreducible_baseChange_of_finrank_eigenspace_eq_one` is the hard
  direction, a self-contained statement whose proof chains four named
  siblings (Lemma 1.4 → 1.5 → 1.6 → step (iv)) and also unpacks irreducibility
  once directly with the shared leaf `isIrreducible_iff_forall` (line 462);
  all five project lemmas are proved earlier in the same file.

The definition `IsAbsolutelyIrreducible` (lines 96-99) is what `unfold` expands
on the first line of the glue, and `baseChange` (lines 76-90) is the operation
both children quantify over; both are shown above so the statements read on
their own.

## Why it is good

1. The parent is closed from its two children in nine lines of glue, one
   `exact` per direction (`check`, lines 484-492).
2. Both children are proved earlier in the same file with no `sorry`, `admit`
   or `axiom` (`check`, lines 405-474).
3. The file header names the two directions and their roles: "the hard
   direction, over an arbitrary field extension `l/k`" and "descent of
   irreducibility (easy direction)" (`author-statement`, lines 38-40).
4. The glue is 9 lines and the two children are 22 and 33 proof lines; the
   hard-direction child calls five project lemmas in its proof
   (`measurement`, lines 453-474).
5. The public-facing `OddRep.isIrreducible_iff_isAbsolutelyIrreducible`
   re-exports this split unchanged as a one-line appeal (`known-use`,
   `FLT/KnownIn1980s/RepresentationTheory/OddAbsIrred.lean` lines 45-49).

In my opinion the detail worth copying is that the hard direction is stated
over an arbitrary extension `l/k`, not just `AlgebraicClosure k`, which is what
keeps the lemma reusable and the glue to a single instantiation.

## When to use it, and when not

Use it when the goal is a biconditional between a property and its base-change
(or more generally a "lifted") analogue, and each direction can be stated as
its own named lemma — the forward direction a real theorem, the reverse a short
descent. A `constructor` plus one `exact` per direction is then all the glue
needed. Avoid it when the two directions share intermediate facts (then the
reverse is not a leaf and a plain `constructor` hides the shared work), or when
one direction is not naturally stated at the same generality as the other, so
the glue has to do more than instantiate a lemma.

## Consequences

The `constructor` on an `↔` creates exactly two goals and no exhaustiveness
obligation. The hard direction is stated over an arbitrary extension `l/k`
rather than `AlgebraicClosure k`, which is what lets the glue instantiate it at
`AlgebraicClosure k`; had it been stated only for the algebraic closure, the
lemma would still close the parent but be less reusable. The easy direction is
a genuine leaf only because its descent argument closes on its own; if it had
to reuse the hard direction's Lemma 1.4–1.6, the two halves would no longer be
independent and the `constructor` split would be misleading.
